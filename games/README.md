# Games

Each team's game lives in its own folder: `games/team-1/` to `games/team-4/`.

- The frontend is a **Vite + TypeScript** app. Start from the reference game in [`server/template/`](../server/template): see [GETTING_STARTED.md](../GETTING_STARTED.md#4-start-your-teams-game).
- Multiplayer runs on Colyseus. Read [server/CLAUDE.md](../server/CLAUDE.md) for how a game uses the platform.
- Your work branches go into `feature/team-N` first, and `feature/team-N` goes into `main`. See [Branches](../CLAUDE.md#branches).
